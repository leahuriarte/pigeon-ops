## Architecture notes

- Flow: `config/port_scenario.json` → `backend/scenario.py` (variant overlay) → `backend/outcomes.py` (action outcomes from route plans) → `backend/decision_engine.py` (ranking, Bayes, EVOI, sensitivity) → `backend/server.py` → `frontend/`.
- `decision_engine.information_value` takes an optional P(signal | road state) table. Without one it uses `drone.accuracy`, an assumed figure for a dispatcher reviewing imagery. `drone.cv_only.likelihoods` is the measured table for automated CV alone, reported as `evoi.cv_only` next to `evoi.break_even_accuracy`.
- Each incident variant names a kind of drone check in `disruption.check` (`crash`, `congestion`, `environment`). The engine still works in two road states, `open` and `blocked`; the check only changes the wording, the clips shown, the assumed accuracy and time, and for heavy traffic the outcome model (`blockage.effect: "slowdown"` delays the truck instead of turning it back).
- `config/community_exposure.json` lists the schools within 300 m of each route (OpenStreetMap, built by `scripts/build_community_exposure.py`). `backend/indicators.py` turns it into the `community_exposure` indicator and each response's `schools_within_300m`.
- `backend/triage.py` is the web check: an LLM agent (or a keyword rule without one) searches the live feeds in `backend/web_feeds.py` (CHP incident log, Caltrans D7 message signs, NWS alerts) or the synthetic `config/web_triage_fixtures.json` near the incident and reports `corroborates`, `contradicts` or `nothing_found`. Only when the dispatcher applies it does `web=<finding>` update the prior with the assumed `decision_model.web_triage.likelihoods`.
- `cv/` is offline and has its own virtual environment (`pip install -r cv/requirements.txt`). Run its scripts as modules from the repo root, for example `python -m cv.evaluate_road_state --model aerial-ensemble`. `aerial-ensemble` combines COCO `yolo11s.pt` with the DOTA aerial model `yolo11m-obb.pt` and is the best detector so far.
- `cv/road_state.py` is pure Python and tested without CV dependencies. It counts closely spaced vehicles inside a hand-drawn road polygon (`cv/road_rois.json`). Its `road_likelihoods` turns the measured confusion table into the `cv_only` table in config.
- The inspection dialog (`frontend/inspection.js`, `backend/inspection.py`) plays top-down drone clips from the committed `cv/review_library/`, built by `python -m cv.prepare_review` from `cv/drone_review.json` and raw clips in `cv/clips/raw/`. `cv/motion.py` measures vehicle speed net of camera motion; `road_state.assess_motion` turns speeds on the marked road into the suggested observation the dispatcher confirms. `drone-ensemble` adds a 640 px OBB pass that finds large trucks in low-altitude footage.
